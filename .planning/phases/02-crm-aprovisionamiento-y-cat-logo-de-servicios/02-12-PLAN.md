Create app/services/historical_access_service.rb:
- `HistoricalAccessService.visible_to(user, organization)` returns ServiceInstance relation
- Logic:
  - Base: instances for organization
  - Filter: `where("contractual_state != ?", "ended").or(where("historical_access_until >= ?", Date.current))`
  - For admin users: bypass historical filter (see all)

Update ServiceInstance scope:
```ruby
scope :with_historical_access, ->(date = Date.current) {
  where("contractual_state != ?", "ended")
    .or(where("historical_access_until IS NOT NULL AND historical_access_until >= ?", date))
}
```

Configuration: ServiceType.default_retention_days used when instance.ended (Plan 11), overrideable per instance via historical_access_until
</action>
