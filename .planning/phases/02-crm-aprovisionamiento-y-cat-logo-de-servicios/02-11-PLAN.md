</read_first>
<action>
Create app/services/health_state_calculator.rb:
- Callable: `HealthStateCalculator.call(instance)` → returns :healthy/:warning/:critical/:unknown
- Logic:
  - unknown: last_heartbeat_at.nil? OR last_heartbeat_at < 2 * freshness_threshold (from ServiceType config)
  - healthy: error_rate < 1% AND latency_ms < threshold AND heartbeat recent
  - warning: error_rate 1-5% OR latency_ms 1-2x threshold
  - critical: error_rate > 5% OR latency_ms > 2x threshold OR heartbeat > freshness_threshold

Thresholds from ServiceType config (freshness_threshold_seconds, error_rate_threshold, latency_threshold_ms)
Defaults if not configured: freshness=300s, error_rate=5%, latency=5000ms

UpdateHealthStatesJob (Solid Queue recurring):
- Runs every 5 minutes
- Finds instances with operational_state IN (running, degraded) AND last_heartbeat_at > 1.hour.ago
- Calculates health, updates health_state
- Triggers operational state transitions via callbacks
</action>
<acceptance_criteria>
- Calculator returns correct health for various metric combinations
- unknown when no heartbeat or stale (> 2x threshold)
- healthy/warning/critical thresholds work
- UpdateHealthStatesJob runs every 5 min (Solid Queue recurring)
- Health changes trigger operational state transitions
- Metrics updated via Phase 3 API (placeholder for now)
</acceptance_criteria>
