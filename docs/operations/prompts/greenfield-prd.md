# Prompt: produce the PRD

Quiero convertir nuestras decisiones de producto en el PRD que gobernara un proyecto de desarrollo autonomo.

Usa solamente decisiones confirmadas y hechos respaldados por el contexto disponible.
No rellenes huecos inventando requisitos.
Cuando algo siga sin resolverse, incluyelo en "Open Decisions".

Produce un documento Markdown listo para guardar como `docs/product/PRD.md` usando la estructura de `docs/product/PRD_TEMPLATE.md`.

Cada requisito debe ser verificable. Asigna IDs estables a requisitos funcionales y no funcionales.
