# Prompt: non-converging blocker

No sigas probando soluciones al azar.

Deten implementacion y resume:

1. evidencia observada;
2. hipotesis descartadas;
3. hipotesis que siguen abiertas;
4. si el bloqueo es de requisitos, arquitectura, implementacion, entorno o tooling;
5. que informacion falta;
6. que decision humana seria necesaria, si realmente existe;
7. siguiente experimento minimo que permita obtener informacion nueva.

No propongas una reescritura como primera respuesta.
